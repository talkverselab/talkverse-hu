# 회화(다이얼로그) — 헝가리어 특이점

공통 원칙(레벨 = 절벽 R1~R4, 턴 수, 독음·설명, 반전, 수위, 변이 파일, 검수)은 여기를 따른다:
**https://talkverse.uk/talkverse/dialogue-rules/** · 절벽 기준표 https://talkverse.uk/cliff/18/

이 문서에는 헝가리어에만 해당하는 것만 적는다.

## 분량·레벨 (2026-11-03 사용자 결정 — 소수언어 fa·hu·my)

- 헝가리어는 절벽 단어 **1,500개**로 만든 소수언어다 → 회화는 **앱 전체 150편까지**, 레벨은 **R1~R3 만**(R4 이상 없음).
- 구간(2026-11-03 형태소 단위로 새로 산정 — 일본어 방식, 사용자 지시): 낱말은 기본형, 격 접미사(모음조화 짝 하나로)·소유 접사·복수 -k·동사 어미 묶음을 각각 1토큰으로 세고 공개 자막 표본(형태소 토큰 약 400만)에서 절대 55/60/70% 로 끊음 → **R1 = 1~105 · R2 = 106~146 · R3 = 147~306**(소수언어라 R3 를 1,500 까지 씀). 1,500개 커버 85.0%, 2,500개 88.6%. 앞선 값(단어형 기준 235·391·1,007, 처음 749·1,291)은 폐기. 자국 영화·드라마 대사 코퍼스가 생기면 다시 산정.
- 편수 나누기(R1·R2·R3 각 몇 편)는 회화 작성이 풀릴 때 공통 원칙의 비율을 150편 안에 맞춰 정한다. 작성 시작은 사용자 지시 뒤.
- 검수 단계(2026-11-03 사용자 지시): 초안 → 자동 검사 → Grok 재작성 → **Gemini 검수**(틀 `~/talkverse/ja/tools/prompts/review_gemini.md`, 결과 `data/review/<편id>_gemini.md`) → 사용자 리뷰. Grok·Gemini 는 사용자 지시가 있을 때만 켠다.
- 반전 비율(공통 원칙 §9, 2026-11-03 공지): **카오스 30% 이상**(150편이면 45편+), 연애·플러팅 편마다 심쿵 한 줄(여성 주도 편 더 많이), 편마다 `twist_type`(chaos·slip·reveal·emotion·ignore), 새 편은 왕초보·초급 위주. 그림 = A·B 쌍 1컷, 말풍선·글자 없음, 인물 기준 그림(`CHARACTERS.md`) 첨부.

## 한글 독음 표기표 (현재 초안 데이터 기준, 2026-11-02 정리)

| 헝가리어 | 독음 | 예 |
|---|---|---|
| a (짧은 a) | 어 | Anna → 언너, magyar → 머져르 |
| á | 아 | kávé → 카베 |
| e / é | 에 / 에 | kérek → 케렉 |
| o, ó / ö, ő | 오 / 외 | jó → 요, köszönöm → 쾨쐬뇜 |
| u, ú / ü, ű | 우 / 위 | sütemény → 쉬테멘 |
| sz | ㅆ | szia → 씨어 |
| s | 시(어말)·슈(자음 앞) | és → 에시, Budapesten → 부더페슈텐 |
| zs | 주 계열 | — |
| cs / c | ㅊ / ㅊ(츠) | csinál → 치날, perc → 페르츠 |
| gy | ㅈ(져·죠) | gyalog → 죨록, egy → 에지 |
| ny / ty | ㄴ(니) / 티 | nyitva → 니트버 |
| j, ly | 이(ㅣ계 반모음) | jó → 요, éjszaka → 에이써커 |
| 겹자음 (tt·kk·ss…) | 받침+된소리로 길게 | itt → 이트, akkor → 어꼬르 |

- 강세는 항상 첫음절 — 독음에 따로 표시하지 않는다.
- 같은 낱말은 모든 편에서 같은 독음으로 쓴다(편마다 흔들리지 않게 이 표에 추가해 가며 맞춘다).

## 말투·변이·성별판

- **기본 변이 = 표준 헝가리어(hu_HU)**. 다른 변이는 없다.
- **반말(tegezés) / 존댓말(magázás·önözés)**: 친구·또래 = te 형태, 가게·관공서·처음 만난 어른 = Ön/Maga + 3인칭 동사. R1 부터 장면에 맞게 섞는다(현재 초안은 반말뿐 — 보완 대상).
- **성별판**: 헝가리어는 문법적 성이 없고 3인칭 대명사도 ő 하나라, 화자 성별에 따라 문장이 바뀌지 않는다. 성별판 파일은 만들지 않는다(이름·호칭만 바꾸면 됨).
- 턴 길이: 교착어라 낱말 수가 적게 보인다 — 길이는 낱말 수보다 음절·형태소 기준으로 R1 짧은 문장(접미사 1~2개)부터 늘린다.
