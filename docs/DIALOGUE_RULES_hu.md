# 굴절어 회화 전략 — 헝가리어 판단 (2026-11-08)

전달문 `~/talkverse/INFLECTED_LANG_STRATEGY.md`(러시아어앱 작성, 사용자 결정 11항목)을 헝가리어(교착어·소수언어)에 대 본 결과. 소수언어 범위(150편·R1~R3)와 Gemini 검수는 그대로. **아래 「다름」 항목은 사용자 답을 받기 전에는 따르지 않는다(§D).**

## 그대로 따르는 것
- B1~B14 회화 원칙(이미 초안 150편이 이 원칙으로 쓰였다 — 표현 풀·채팅·반전 비율·감정 열·독음·저장 구조).
- A2 비율 원칙(핵심 1 : 변형 9) — 변형 카드는 회화 밖 콘텐츠라 동결이 풀린 뒤.
- A7 — 로마자 언어라 R0 = 짧은 회화 편만(문자 카드 없음). R0 는 R1 중 짧은 편을 골라 분리.
- A9 — 헝가리어는 문법적 성이 없어 성별판(`hu_f`) 불필요. 음성은 모든 턴 남·여 두 줄(이름만 다름).
- A10 — 라임 화자는 공통 외계인 캐릭터(시트는 uk 세션 답 대기).
