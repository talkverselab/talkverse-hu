## 1. 헝가리어의 강점 — 무엇을 보여 줄까

헝가리어는 낱말 끝에 **접미사를 줄줄이 붙여** 뜻을 만든다(`Koreá|ból` 한국|에서, `magyar|od` 헝가리어|너의, `vel|em` 함께|나와). 한국어 조사와 닮아서 한국 학습자에게는 오히려 **가장 친숙한 지점**이다. 그리고 접미사는 앞 모음에 맞춰 모양이 바뀐다(**모음조화**: `-ban/-ben`, `-ból/-ből`, `-val/-vel`).
그래서 두 가지를 화면에 그린다.

1. **접미사 색칠 + 분해 시트** — 문장 속 낱말을 「어간 | 접미사」로 나눠 접미사만 자두색으로. 탭하면 아래에서 시트가 올라와 `Koreá + -ból = 한국 + 에서` 처럼 한국어 조사와 나란히 보여 준다.
2. **모음조화 배지** — 접미사 옆 작은 점(뒷모음 ● 남색 / 앞모음 ○ 자두). 시트에서는 짝(`-ból ↔ -ből`)을 같이 보여 「왜 이 모양인지」를 한눈에.

나머지(장면 컷·말풍선·캡션·스크립트·재생·속도·자막 칩·편 끝 연출·성과 데스크)는 시안 02 그대로.

│ 진행│     안녕! 나는 민준이야.      │ │        ( 말풍선: Honnan jössz? )  │ │

- 자막 칩에 **「접미사」** 하나 추가: 켜면 스크립트·캡션의 접미사가 자두색으로 칠해진다(기본 켬).
- 시트는 오른쪽 칸 아래쪽에 겹치는 높이 40% 패널, 바깥 탭으로 닫힘. 폰에서는 화면 아래 시트.

## 3. 홈(배우기) — 기초에 「접미사 지도」 한 칸

```
┌────┬──────────────────────────────┬──────────────────────────────────────┐
│레일│ Szia! (파스텔 메시 상단)       │ 오늘의 컷                             │
│ 홈●│ 오늘의 학습 카드              │ ┌──────────────────────────────────┐ │
│    │ 기초                          │ │ [장면 컷]  말풍선: Szia!          │ │
│    │ ┌접미사 지도┐┌동사 활용┐┌단어┐│ └──────────────────────────────────┘ │
│    │ │ -ban -ból ││ V       ││ W  ││ 첫 인사 · 사랑 · 8턴  [읽기 시작]   │
│    │ │ -val  ●○  ││         ││    ││                                      │
│    │ └───────────┘└─────────┘└────┘│                                      │
│    │ 회화 · 주제별                  │                                      │
└────┴──────────────────────────────┴──────────────────────────────────────┘
```
- 「접미사 지도」 = 자주 나오는 격 접미사 묶음(장소: 안·밖·위 / 출발·도착 / 함께·도구) 타일. 탭하면 묶음 카드 → 그 접미사가 나온 회화 문장으로 이동.
- 그 밖의 메뉴는 지금 앱 그대로(회화·문법·문장 카드·말하기·청크 검색·동사 활용·단어·표현·빈도 단어·단어 카드).

## 4. 「나」 탭 성과 — 한 줄 추가

- 시안 02 데스크(이번 주 한 줄 → 커버율 링 → 절벽 마일스톤 → 주간 점 → 주제별 격자)에 **「만난 접미사 n종」** 한 줄(편에서 탭해 본 접미사 수).
